# BOZO v4.12.0 — Daily BOZO

Built on v4.11.8.

Adds Daily Puzzle public page, California-time scheduling, monthly archive, solve streaks, progressive hints, post-solve explanations, comments/replies/likes/reports, Position Analysis handoff, and Owner/authorized-staff Daily Puzzle Studio with visual continuation recording and monthly scheduling.

## Required
Run `BOZO_V4120_DAILY_BOZO.sql` once in Supabase before testing.

## Timezone
Daily rollover uses `America/Los_Angeles`, which automatically handles PST/PDT.
