# Universal Board Annotations — v3.2.0

BOZO now supports user-drawn board annotations across Study Mode, Game Review, Studies, Recall Training, Opening Puzzles, BOZO Bot, and Friend Duels.

## Controls
- Right-click a square: toggle highlight
- Right-drag from one square to another: toggle arrow
- Shift + right-click/right-drag: red
- Ctrl/Cmd + right-click/right-drag: blue
- Alt + right-click/right-drag: yellow
- No modifier: green
- Clear Marks buttons remove user annotations

Study/Game Review user annotations use a separate SVG layer from BOZO Coach annotations, so the coach can continue drawing its own explanatory arrows without overwriting the user's marks. User marks reset when the underlying position or orientation changes.
