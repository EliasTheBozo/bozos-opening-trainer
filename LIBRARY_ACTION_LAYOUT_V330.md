# BOZO v3.3.0 — Opening Library Action Layout

- Study, Train, and Puzzle are visible on every Opening Library card.
- Opening families now also expose Train and Puzzle using the family's preview line.
- Browse variations remains visible for multi-line families.
- Common Responses, Play bot, and Challenge are grouped into a compact More menu.
- Expanded variation rows use the same Study / Train / Puzzle / More hierarchy.
- Responsive layouts collapse cleanly at tablet and phone widths.
- Frontend asset filenames were bumped to v3.3.0 to avoid stale Cloudflare/browser caches.
