# BOZO v4.7.1

Fixes:
- Supporter crest no longer flashes during rated-game polling. Opponent cosmetic state is cached for the active opponent and is not cleared during position refreshes.
- Review Game post-game button now refreshes game history if needed, loads the PGN directly into Review, and gives visible feedback.
- Rematch post-game button now sends the rematch offer directly, reopens the rated game panel, updates negotiation UI, and confirms that the offer was sent.
