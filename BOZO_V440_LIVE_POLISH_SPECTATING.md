# BOZO v4.4.0
Adds last-move highlighting, check highlighting, captured material, connection/reconnecting state, and read-only spectating from accepted friend profiles.

Spectators get a live board, clocks, ratings, move list, check state, last move, and captured material. They cannot move, resign, offer draws, request rematches, restart, or annotate.

Requires BOZO_V440_SPECTATING.sql. No rated-match Edge Function change is required.
